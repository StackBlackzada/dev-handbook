# ✅ Aprovação de ferramentas

[← Voltar ao índice](../README.md)

1. Sempre preferir as ferramentas listadas neste guia.
2. Novas ferramentas só entram após aprovação do mantenedor e adição neste repositório.
3. Para propor uma ferramenta, abra uma Issue com o template **Sugerir nova ferramenta**.
4. A proposta precisa responder:
   - Qual problema resolve?
   - Substitui alguma ferramenta que já temos?
   - Qual o custo?
   - Onde ficam os dados (e isso é um problema para clientes)?
5. Depois de aprovada, abra um Pull Request adicionando o link na categoria certa em `docs/`.
6. Ferramentas que saem de uso devem ser removidas do guia (ou marcadas como *descontinuadas*) no mesmo PR.
