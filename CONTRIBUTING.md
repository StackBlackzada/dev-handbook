# 🤝 Como contribuir

Contribuições são bem-vindas, inclusive de fora da empresa.

1. Abra uma [Issue](../../issues/new?template=nova-ferramenta.yml) sugerindo a ferramenta.
2. Depois de aprovada pelo mantenedor ([@CaioSouzx00](https://github.com/CaioSouzx00)), faça um **Pull Request** adicionando o link na categoria certa em `docs/`.
3. Mantenha o formato limpo e organizado (mesmas colunas das tabelas, links oficiais).
4. Teste o link antes de abrir o PR.

Regras completas: [regras/aprovacao-de-ferramentas.md](regras/aprovacao-de-ferramentas.md)
