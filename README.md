## 📌 Regras de uso

1. Sempre preferir ferramentas listadas neste guia.
2. Novas ferramentas só entram após aprovação do mantenedor e adição neste repositório.
3. Agentes de IA devem ser usados com cuidado em código de produção (**revisão humana obrigatória**).
4. Mantenha as Skills do Hermes atualizadas com os padrões da empresa.

Detalhes: [uso de IA em produção](regras/uso-de-ia-em-producao.md) · [aprovação de ferramentas](regras/aprovacao-de-ferramentas.md)
